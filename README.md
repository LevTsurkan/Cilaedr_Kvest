«Симулятор Силаэдра» — текстовый квест в стенах школы
«Симулятор Силаэдра» — это текстовый квест на Python, где вы исследуете школу, собираете предметы, взаимодействуете с персонажами и сражаетесь с финальным боссом. Вас ждут неожиданные повороты, абсурдные ситуации и несколько концовок (в том числе «смерть» и «победа»).

🎮 Геймплей
Вы начинаете в прихожей школы с одним лишь пропуском. Ваша задача — исследовать этажи, находить ключи и полезные предметы, избегать лишних объяснительных (3 объяснительные = исключение из школы) и в конце победить монстра «Пчелоптицепеса».

Особенности игры:

Исследование локаций. Перемещайтесь между этажами, комнатами, задним двором и другими зонами.
Сбор предметов. Ключи, отвертка, колба с мылом, корм для кота — каждый предмет важен.
Взаимодействие с персонажами. Поговорите с охранницей, завхозом, Ингой Александровной, Олегом Сергеевичем и волшебным Котом.
Боевая система. В финальной битве с боссом нужно выбирать удары по уязвимым местам.
Звуковое сопровождение. Игра включает фоновую музыку и трек битвы с боссом.
Случайные события. Некоторые встречи и реакции персонажей определяются генератором случайных чисел.
📦 Зависимости и модули
Для запуска игры необходимо установить и иметь следующие модули и файлы:

Python-модули
В коде используются стандартные библиотеки Python, дополнительные модули скачивать не нужно.

# Ничего дополнительно устанавливать не требуется — игра работает на стандартной библиотеке.
Используемые модули:

pygame — для воспроизведения музыки.
os — для работы с путями к файлам.
time — для создания пауз между репликами.
random — для генерации случайных событий.
⚠️ Важно: Хотя pygame входит в стандартную экосистему Python, это не встроенный модуль. Его нужно установить отдельно.

Установите pygame командой:
tall pygame
Необходимые файлы в папке проекта
Игра ожидает, что в той же папке, где лежит скрипт, будут следующие файлы:

фоновая музыка.mp3 — фоновый трек, который играет на протяжении всей игры.
босс.mp3 — музыкальный трек для финальной битвы с Пчелоптицепесом.
Без этих файлов игра выдаст ошибку при попытке загрузить музыку.

🚀 Как запустить игру
Установите зависимости:

bash
pip install pygame
Подготовьте файлы:

Положите файлы фоновая музыка.mp3 и босс.mp3 в ту же папку, где находится скрипт игры (например, game.py).

Запустите игру:

python game.py
(замените game.py на реальное имя вашего файла с кодом)

Следуйте инструкциям в консоли. Вводите цифры, соответствующие выбранным действиям.

⚠️ Возможные проблемы и решения
Ошибка pygame.error: File not found: Убедитесь, что файлы .mp3 лежат в той же директории, что и скрипт, и их названия совпадают точно (включая пробелы и регистр букв).
Ошибка ModuleNotFoundError: No module named 'pygame': Выполните команду pip install pygame.
Игра «зависает» после ввода: Это нормально — в коде используются задержки (time.sleep), чтобы создать эффект живой речи. Подождите несколько секунд.
